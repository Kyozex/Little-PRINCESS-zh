# Little PRINCESS 简体中文汉化版（Champion Soft · 1987 · MSX2）

[![新增内容许可：CC BY-NC-SA 4.0](https://img.shields.io/badge/%E6%96%B0%E5%A2%9E%E5%86%85%E5%AE%B9-CC%20BY--NC--SA%204.0-lightgrey.svg)](LICENSE)

《Little PRINCESS》是 **1987 年 11 月**由 **Champion Soft** 开发、**アリスソフト（AliceSoft）** 发行的
MSX2 文字冒险游戏，以 FD 介质发行。本作是随磁盘杂志《レモネード》创刊号附录赠送的《さらわれた美樹ちゃん》
的重制型作品，两者的展开与通关流程截然不同，请勿混用攻略。

本仓库是《Little PRINCESS》的**简体中文汉化版**。
提供 Windows 单文件可执行程序，双击即玩、无外部依赖、无需安装；
随附完整**中文流程攻略**，以及**拼音指令对照表**与**英语指令对照表**。

> [!IMPORTANT]
> 本仓库是**非官方**的个人汉化与整理项目，与 Champion Soft、AliceSoft 及其关联方不存在任何隶属或授权关系。
> 原作品著作权归原作者及 AliceSoft 所有。本仓库的再分发严格遵循 AliceSoft《配布フリー宣言》，

## 三、启动方式

1. 将 `Little PRINCESS.exe` 放入一个**专用且固定**的目录，例如 `D:\Games\Little PRINCESS`。
2. 双击运行。首次启动会短暂解包游戏资源，随后自动打开游戏窗口。
3. 游戏窗口标题为 `Little PRINCESS　十字羽个人汉化`。

> [!TIP]
> **请不要随意移动这个 EXE。** 启动器为游戏分配的本地服务端口由 EXE 所在目录推导，而存档绑定在该端口对应的
> 浏览器存储区中；换目录后旧存档将无法被读取。

## 四、操作说明

### 4.1 指令输入

游戏在画面底部的 `COMMAND` 栏推进：**每输入一条指令按一次 Enter**。

除方向移动外，一切指令都由「动作指令 + 空格 + 对象指令」组成，动作与对象之间**恰好一个半角空格**：

```
查看 草丛        拿取 钥匙        对话 女孩        询问 提示
给出 金枪鱼罐头   打开 邮箱        投掷 斧头        使用 毛巾
```

方向为独立指令，单独输入、不带对象：`东`　`西`　`南`　`北`。

汉化版提供三种等价的输入方式：

- **无声调拼音（推荐）**　切换到英文输入法，直接敲拼音；词内音节连写，动作与对象之间用空格分隔。
  输入栏会即时把拼音合成为汉字，例如 `shiyong yaoshi` 显示为「使用 钥匙」，`bei` 显示为「北」。
  无需启用系统中文输入法。完整词表见 `Little PRINCESS 拼音指令对照.txt`。
- **英语指令**　本汉化版内置的英语指令同样可用，例如 `look girl`、`use key`、`north`、`password`。
  原版只接受日文指令，这套英语指令的识别与合成逻辑由本汉化版自行编写。
  写法见 `Little PRINCESS 英文指令对照.txt`。
- **汉字**　指令栏中显示的汉字是拼音的合成结果；若输入法直接送出汉字，游戏将无法识别。

未收录于词典的词条不会被合成，会原样留在输入栏中，游戏按「无法理解」处理。

### 4.2 特殊指令

| 目的 | 拼音写法（任选其一） | 快捷键 |
| --- | --- | --- |
| 存档 | `baocun`、`cundang`、`baocunyouxi`、`youxibaocun`、`youxicundang`、`cundangyouxi`、`cunchu`、`chucun`、`youxicunchu`、`youxichucun` | `F3` |
| 读档 | `dudang`、`duqu`、`duquyouxi`、`youxiduqu`、`dudangyouxi`、`youxidudang` | `F5` |
| 打开物品列表 | `wupin` | `F1` |

### 4.3 窗口与全屏

| 按键 | 行为 |
| --- | --- |
| `F11` | 进入 / 退出全屏 |
| `Esc` | 退出全屏 |

全屏时画面按原比例缩放，宽屏显示器两侧留黑边，不会拉伸变形。启动器会按显示器的缩放比例设置独立游戏窗口；
把窗口拖到另一台显示器时，会按新显示器的缩放重新调整窗口尺寸，画面不会出现黑边。

### 4.4 截图

在游戏画面上**单击右键**，可在菜单中选择：

- **将图像另存为…**　通过系统保存对话框直接写入 PNG 文件，不会触发浏览器下载提示；默认文件名取本机时间，
  例如 `lp-20261020-225916.png`，且不包含窗口标题栏。
- **复制图像**　把当前画面复制到剪贴板。

## 五、存档与本地数据

启动器会在下列目录中保存全部运行时数据，卸载游戏时删除该目录即可完全清除：

```
%LOCALAPPDATA%\MugenWorkbench\LittlePrincessBrowser\
├── game\            已解包的游戏资源（按封包指纹分目录存放）
├── window-sizing.log 窗口尺寸与显示器适配的运行日志
└── …                Edge 用户数据，游戏存档保存在其中
```

游戏本身使用浏览器本地存储保存进度，键名为 `lp32-save`，与上述目录内的 Edge 用户数据一并留存。

## 六、汉化说明

- **译文范围**　共 **889** 条文本条目已完成简体中文翻译，由人工翻译，并经人工逐条校对。
- **游戏逻辑零改动**　场景状态码、指令编号、分支判定与结局条件全部沿用原版，仅替换显示文本。
- **新增英语与拼音输入**　原版只接受日文指令。本汉化版自行编写了英语指令的识别逻辑，
  并新增无声调拼音合成，输入栏实时显示汉字；
  有歧义的候选同义词不进入词典，英语指令与拼音指令指向同一套动作与对象。
- **画面与窗口适配**　修正了画布尺寸与窗口尺寸的换算规则：缩放比例在 125% 及以上的显示器上使用
  582×424 画布，启动器据同一组参数调整窗口，跨显示器拖动时不会出现黑边。
- **专有名词**　人名、杂志名等专有名词按原作保留或采用通行译名，个别专名保留原文。
