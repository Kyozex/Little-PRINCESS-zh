  Little PRINCESS　中文流程攻略（仅限十字羽个人汉化版）
================================================================================

本攻略以日文攻略页 https://w.atwiki.jp/retropcgame/pages/458.html 为底稿，
并逐条对照本汉化版封包内的真实指令表与场景数据校验过：

  · 主线步骤全部是游戏中确实存在的「动作 + 空格 + 对象」指令；
  · 附录 A 把每个房间能输入的指令全部列了出来（连同每句回答的条件），
    是逐条对着封包里的指令表穷举出来的，而不只验证了旧攻略写过的内容。

  本次修订改正的事实错误：

  · 「吃掉 苹果」会卡死流程是错的，吃完还能从「苹果园」再摘；
  · 寂寞的女孩要的第三件礼物是池塘里捞上来的十字架，
    惠子给的是斧头和线索，不会给十字架；
  · 在地下室「打开 棺材」只会开棺，不会给十字架，必须用「拿取 十字架」；
  · 「攻击」和「袭击」是两个不同的动作，「攻击」是战斗，「袭击」是色色，你们懂的；
  · 哈尼那里问不出年龄，而是能「询问 爱好」；
  · 不能在拦路女孩处给出钻石和红宝石是错的——三颗宝石任选其一给出即可，
    后续没有必须用到宝石的地方；
  · 从小屋前折返回池塘的第 2 步是「东」，不是「南」。

【写在前面】
────────────────────────────────────────────────────────────────────────────────

  1. 指令一律写成「动作 对象」，中间恰好一个半角空格，例如：
         吃掉 竹笋　　给出 十字架　　使用 毛巾　　给出 蓝宝石
     空格不是装饰，少空格或把空格换成别的字符，指令就不会被识别。

  2. 方向是独立指令，不带对象，单独输入：
         东　　西　　南　　北

  3. 「×2」「×3」表示把同一条指令连续输入两次、三次，
     不是把「×2」这几个字符打进 COMMAND 栏。

  4. 「第 N 步」是推荐执行顺序，不要随意跳步；同一场景内多次查看同一对象
     往往才会推进状态（例如草丛、石头），原版设计如此，这不是无意义的重复。

  5. 括号中的补充说明是写给你看的，不要输入到 COMMAND 栏。

================================================================================
  一、怎么操作
================================================================================

1.1 输入方式

  游戏在画面底部的 COMMAND 栏推进：每输入一条指令按一次 Enter。
  原版文本全是假名，玩家敲英文字母会自动拼成片假名指令；汉化版改成敲
  无声调拼音自动合成汉字，无效词语或拼错的拼音不会被合成，会原样留在栏里。
  所以不需要开系统中文输入法，直接敲拼音即可。

  例：敲 chakan yanshi 会显示成「查看 岩石」；敲 bei 会显示成「北」。

  在初次尝试汉化时，我优先想到的不是拼音，而是英文指令。虽然后续增加了自动拼音功能，
  但英文指令都仍然可用，英文写法见《Little PRINCESS 英文指令对照.txt》。
  这个英文指令和英版的《Little PRINCESS》并无参照关系（我就没下载过这个游戏），因此可能有许多出入。

1.2 指令的基本构成

  除方向移动外，一切指令都由「动作指令 + 空格 + 对象指令」组成：

      查看 草丛　　　　拿取 钥匙　　　　对话 女孩　　　　询问 提示
      给出 金枪鱼罐头　打开 邮箱　　　　投掷 斧头　　　　使用 毛巾
      爬上 楼梯　　　　爬下 楼梯　　　　移动 床　　　　　说 可爱
      说 暗号　　　　　对话 Pon Pon

  常见动作词与近义词（同一动作任选其一即可）：

      查看 ← 查找 / 调查 / 观察 / 观看 / 检查 / 检视 / 看 / 探查
      拿取 ← 捡起 / 取得 / 拾取 / 取走 / 摘取 / 拿
      对话 ← 交谈 / 谈话 / 聊天 / 打招呼 / 说
      询问 ← 打听 / 提问 / 问
      给出 ← 给 / 交给 / 给予 / 递给 / 交付
      打开 ← 开启 / 敞开
      进入 ← 进去 / 进入其中 / 走进
      离开 ← 出去 / 走出
      投掷 ← 扔 / 抛 / 掷出 / 丢弃 / 弃置 / 丢
      吃掉 ← 吃 / 进食
      移动 ← 挪动 / 推动 / 搬动 / 朝 / 朝着 / 去 / 向
      爬上 ← 攀爬 / 登上 / 上楼
      爬下 ← 下去 / 走下 / 下楼
      使用 ← 用
      殴打 ← 打 / 揍 / 拍打 / 敲击
      对战 ← 战斗 / 交战 / 迎战
      袭击 ← 侵害 / 侵犯 / 冒犯 / 扑向 / 突袭 / 袭向 / 扒下 / 扒光 /
        　　 脱下 / 脱光 / 脱去 / 脱衣

  同一对象也允许多种写法（词典会自动归一），例如：

      希拉拉柠檬 ← 柠檬 / 柠果 / 希拉拉
      红宝石　　 ← 红宝玉 / 红色宝石 / 红玉
      蓝宝石　　 ← 蓝色宝石
      金枪鱼罐头 ← 吞拿鱼罐头 / 金枪鱼 / 罐头 / 鱼罐头
      毛绒玩偶　 ← 布偶 / 毛绒玩具 / 玩偶 / 人偶 / 娃娃
      十字架　　 ← 十架 / 十字架圣物
      楼梯　　　 ← 阶梯 / 台阶
      棺材　　　 ← 棺木 / 灵柩
      金斧头　　 ← 金斧 / 金制斧头
      银斧头　　 ← 银斧 / 银制斧头 / 白银斧
      斧头　　　 ← 斧 / 斧子
      哈尼　　　 ← 哈尼瓦 / 土偶
      钥匙　　　 ← 锁匙
      门　　　　 ← 房门 / 大门 / 城门
      房子　　　 ← 住宅 / 别墅 / 宅子
      草丛　　　 ← 草 / 小草
      树　　　　 ← 大树 / 树木
      石头　　　 ← 岩石
      苹果　　　 ← 林檎
      竹笋　　　 ← 嫩笋 / 笋
      毛巾　　　 ← 擦手巾 / 浴巾
      美树　　　 ← 小美树 / 美树小姐

  三个容易搞混的动作编号：

　　　袭击＝第 20 号动作，同义词很多：侵害 / 侵犯 / 冒犯 / 扑向 / 突袭 /
　　　　　　袭向 / 扒下 / 扒光 / 脱下 / 脱光 / 脱去 / 脱衣。
　　　　　　都是同一个动作；
　　　攻击＝第 3 号动作，所以「攻击 女孩」不是「袭击 女孩」；
　　　殴打＝第 27 号动作，只是拍打一下，多数场合无害。

  「袭击 女孩」在不同场景含义有所不同：在惠子那里是主线必需动作，
  在拦路女孩、倒地女孩、德古拉的女儿那里则是别的效果（详见第二节与附录）。

  还有一个容易漏掉的同义动作：「扶起」（也叫 叫起 / 叫醒 / 唤醒）。
  它在倒地女孩那里和「袭击 女孩」一样致命，见第二节第 1 条。

1.3 系统功能（原版要按快捷键，本汉化版可直接用指令）

      查看随身物品：输入「物品」后回车（原版 F1）
      存档：　　　　 输入「save」「存档」「保存」后回车（原版 F3）
      读档：　　　　 输入「load」「读档」「读取」后回车（原版 F5）
      全屏：　　　　 F11（退出全屏是Esc）
      截屏：　　　 　在画面上点右键，选择「将图像另存为…」或「复制图像」即可

1.4 存档安全须知（很重要）

  这个游戏有真实存在的坏档与死档：某些动作一旦执行，物品会被夺走、
  场景会被锁死，且无法靠走回头路补救。原则是：

      · 每次执行「消耗品」类动作（交出物品、吃掉东西）之前先存档；
      · 拿到新道具后立刻存档；
      · 主线推进到新场景后立刻存档；
      · 一旦发现屏幕上的提示不对，不要继续乱试，直接读档回到上一个存档点。

  另外，房间里的道具大多是「一次性」的：拿走之后原对象就消失了，
  但通常仍可再次查看该场景确认。
  最坑的是只有一个存档位，而且很多操作不会立刻让你卡关，
  而是在很久之后的某个场景中……唉，还是跟着我的攻略走吧

================================================================================
  二、会卡死或损坏存档的行为
================================================================================

以下 5 条是全篇最重要的事，务必避开。它们共同点是：可以执行的操作，
而且当场不会报错，但会在此后某个节点大爆特爆。

  ■ 1. 不要碰倒在地上的女孩。
      「袭击 女孩」会把你打回起点，同时希拉拉柠檬和钻石被永久夺走。
      只能尝试「查看 女孩」，或者「对话 女孩」／「殴打 女孩」（都无害）。

      同一个陷阱还有第二个入口：「扶起 女孩」（同义词：叫起 / 叫醒 / 唤醒）。
      这同样会触发「被打回起点 + 柠檬与钻石被夺走」，
      只是台词不同（「女孩醒了过来」）。所以碰到倒地女孩时，
      「袭击」和「扶起」两个动作都不能用。

      另外，「袭击 女孩」的 13 种写法（侵害 / 侵犯 / 冒犯 / 扑向 / 突袭 /
      袭向 / 扒下 / 扒光 / 脱下 / 脱光 / 脱去 / 脱衣 / 袭击）
      在这里全部一样致命。

  ■ 2. 希拉拉柠檬只能吃一次，而且必须留到城堡里的「阴森走廊」吃。
      在起点吃掉后，走廊吃柠檬会得到「希拉拉　希拉拉…」的敷衍台词，
      北边永远过不去；而柠檬又不能重新摘，死档。
      正确用法：进入阴森走廊后再「吃掉 希拉拉柠檬」，然后向北。

  ■ 3. 竹笋在交给惠子之前不能吃。
      吃了以后「拿取 竹笋」只会得到「竹笋　那是啥 / 我不知道啊」，
      竹笋再也拿不到，也就换不到斧头；没有斧头就捞不出池塘里的十字架，
      主线到此为止。
      （如果已经用竹笋换过斧头，此时再吃不会有任何反应，斧头也不会消失，
       所以这条只针对还没换斧头的时候。）

  ■ 4. 不要和德古拉对战。「对战 德古拉」必败，而且被打回起点。
      唯一的通关方式是「说 暗号」（咒语「Pon Pon」）。
      不过必败不等于死档：只要地下室进行过「拿取 十字架」，
      就能按第六部分的恢复流程走回来。不过非要绕远路通关纯属没事找事。

  ■ 5. 地下室的十字架务必用「拿取 十字架」拿。
      「拿取 十字架」= 开棺 + 拿到十字架 + 进入德古拉房间，一步到位；
      「打开 棺材」只会提示「你试着打开棺材」，十字架不会到手，
      此时再输入「拿取 十字架」也不行。
      一旦战败被打回，并且身上没有十字架，宅邸里的女孩就会回答「你没有十字架」，
      再也进不了城堡，就完蛋了。

  另外三个提醒：

  · 拦路女孩处交钻石、红宝石、蓝宝石均可。
  · 德古拉的女儿处不要「给出 希拉拉柠檬」：
    她会说「干得好　这不正是希拉拉柠檬吗」，然后柠檬消失，走廊就过不去了。
  · 不要把宝石扔掉。「投掷 蓝宝石」（丢 / 扔 / 丢弃 / 弃置 / 抛 都一样）
    会让它「飞向遥远的天边」，之后就再也拿不到它了。
    扔掉蓝宝石之后再到拦路女孩处，她会拒绝放行，需要额外一颗宝石。
    钻石和红宝石扔掉同样拿不回来，
    只是它们本来就是可选礼物，扔了不会卡主线。

  最后，吃苹果并不会卡死流程。
  「吃掉 苹果」之后回到苹果园仍能再次「拿取 苹果」，
  所以它不属于死档操作。真正吃不得的是竹笋和希拉拉柠檬。

  少一样或顺序不对，她只会重复「我想要十字架　有了那个　我就……」。

================================================================================

只有一种情况需要恢复：与德古拉对战失败，被打回起点。
先判断自己是否还有重来一次的机会，也就是看十字架还在不在身上。

  情况一：地下室是用「拿取 十字架」拿的十字架 → 可以重来。

    下面这串指令可以快速走到通关，按顺序输入即可：

      1. 东　（到苹果园）
      2. 东　（到宅邸前）
      3. 进入 房子
      4. 给出 十字架　　　（宅邸里的女孩重新收下十字架，场景回到城堡大厅）
      5. 北　（城堡大厅 → 楼梯）
      6. 爬上 楼梯　　　（爬过一次了，这次一次就能上到二楼，楼梯不再惨叫）
      7. 北　（穿过画中的女孩 → 阴森走廊）
      8. 北　（柠檬已经吃过，幻象已散，直接通过）
      9. 爬下 楼梯
      10. 拿取 十字架
      11. 说 暗号

  情况二：地下室是用「打开 棺材」开的 → 身上没有十字架，宅邸里的女孩
    不再接受「给出 十字架」（只会提示「你没有十字架」），无法再进城堡，
    流程永久卡死。此时只能读档，回到进入地下室之前的存档点重新来过。

  其它失败情况（被拦路女孩重新拦下、误袭击倒地女孩、误吃柠檬或竹笋）
  同样以读档为准，不要试图在当前局面硬凑条件。
  尤其是误吃柠檬和误吃竹笋，这两件事无法在游戏内补救。

================================================================================
  附录 A：每个场景的全部可用指令
================================================================================

  这一节是我逐个房间穷举出来的，方法如下：
  把每个房间自己的三条指令表和全局表 KE4/KE5/KE6 全部展开，
  再把这个指令会检查到的每一个标记（旗标）在游戏里真正可能的取值
  全部枚举一遍，每一种组合都放回原版引擎跑一次。
  理论上，下文是所有可运行的指令了。

  · 「方向」一行是这个房间的四个走法。
  · 一条指令常常有好几种回答，看你之前在这个房间做过什么。
    同一指令下的几条回答，是按游戏判定的先后顺序排的：
    第一条条件成立的，就是游戏给你的那句回答。
    「需 …」写的就是出现这句回答的条件。
  · 括号里的「→ 进入 XX」说明这条指令会把你带到别的房间。
  · 任何房间都能输入的通用指令（吃掉、给出、投掷、保存…）见附录 B。
  · 同一件事游戏有很多种说法，下面写的是其中一种；
    例如「查看 墙壁」写成「查看 墙」、「拿取 刀」写成「拿取 小刀」，
    在游戏里是等价的。
  · 标「★」的行为虽然能执行，但会损坏存档或影响剧情，请读说明。

================================================================================
  附录 C：常见错误写法
================================================================================

以下写法很容易错拼，但游戏词典里没有这些词，输入后不会合成，
指令会被无视。建议按右栏改写。

   错误写法            正确写法
  ------------------- ----------------------------------------------------------
   捡 钥匙　　　　　　　拿取 钥匙
   前往 城堡　　　　　　直接输入方向：东 / 西 / 南 / 北
   查看 书　　　　　　　查看 书本
   拿取 书　　　　　　　拿取 书本
   对话 德古拉　　　　　说 暗号；要打才用 对战 德古拉

  另有一个方向性笔误：
  · 从小屋前往池塘的折返中，第 2 步是「东」，不是「南」。

  最后澄清原稿中的错误说法：
  · 「吃掉 苹果」会卡死流程是错的——苹果树上可以无限摘苹果；
  · 不能在拦路女孩处给出钻石和红宝石是错的——三颗宝石任选其一给出即可，
    后续没有必须用到宝石的地方；
  · 「打开 棺材」也能拿到十字架是错的——它只能开棺，十字架必须用
    「拿取 十字架」拿。
